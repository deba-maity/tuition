Define WaterBill with String name, int units and double bill. accept() reads name and non-negative units; calculate() charges Rs 5 per unit for the first 50 units, Rs 7 for the next 50, and Rs 9 thereafter. Add 5% of the calculated charge only when units exceed 100. display() prints name and bill. main() must create an object and invoke the methods. Input: a full name on one line, then units.
Worked solution / model answer
Keep fields at class scope. Carry forward the cost of each completed slab, then add the surcharge.
Check: A progressive slab is different from charging every unit at the final rate. Test both sides of each boundary.

import java.util.Scanner;
public class WaterBill {
    String name;
    int units;
    double bill;
    void accept() {
        Scanner sc = new Scanner(System.in);
        name = sc.nextLine();
        units = sc.nextInt();
    }
    void calculate() {
        if (units <= 50) bill = units * 5.0;
        else if (units <= 100)
            bill = 250 + (units - 50) * 7.0;
        else {
            bill = 600 + (units - 100) * 9.0;
            bill += bill * 0.05;
        }
    }
    void display() {
        System.out.println(name);
        System.out.println(bill);
    }
    public static void main(String[] args) {
        WaterBill w = new WaterBill();
        w.accept();
        w.calculate();
        w.display();
    }
}

Overload show: void show(int rows) prints rows lines, with line i containing i through rows; int show(String text, char target) returns the case-sensitive frequency of target; double show(double radius) returns 2 * Math.PI * radius (circumference). main() demonstrates show(5), show("ABRACADABRA",'A') and show(3.0).
Worked solution / model answer
The parameter lists select the overload. Use nested for loops for the triangle and a single String traversal for frequency.
Check: Return type alone does not overload a method. show(2) chooses the int overload; show(2.0) chooses double.

public class Revision {
    void show(int rows) {
        for (int i = 1; i <= rows; i++) {
            for (int j = i; j <= rows; j++) {
                if (j > i) System.out.print(" ");
                System.out.print(j);
            }
            System.out.println();
        }
    }
    int show(String text, char target) {
        int count = 0;
        for (int i = 0; i < text.length(); i++)
            if (text.charAt(i) == target) count++;
        return count;
    }
    double show(double radius) {
        return 2 * Math.PI * radius;
    }
    public static void main(String[] args) {
        Revision r = new Revision();
        r.show(5);
        System.out.println(r.show("ABRACADABRA", 'A'));
        System.out.println(r.show(3.0));
    }
}
5 [15]
Accept 7 single-character tokens. Copy them into a second array. Sort the copy in descending character-code order using bubble sort only. Display the original and sorted sequences.
Worked solution / model answer
After each left-to-right pass, the greatest remaining character reaches the right end.
Check: Use j < length - 1 - pass. Preserve the original by copying elements, not by assigning the same array reference.

import java.util.Scanner;
public class BubbleChars {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        char[] original = new char[7], a = new char[7];
        for (int i = 0; i < 7; i++) {
            original[i] = sc.next().charAt(0);
            a[i] = original[i];
        }
        for (int pass = 0; pass < a.length - 1; pass++)
            for (int j = 0; j < a.length - 1 - pass; j++)
                if (a[j] < a[j + 1]) {
                    char temp = a[j];
                    a[j] = a[j + 1];
                    a[j + 1] = temp;
                }
        for (int i = 0; i < 7; i++)
            System.out.print(original[i] + " ");
        System.out.println();
        for (int i = 0; i < 7; i++)
            System.out.print(a[i] + " ");
        System.out.println();
    }
}

Read positive n, followed by n pairs of one-word product name and price, then a one-word key. Using linear search, print the price of the first matching name, with case-sensitive matching. If absent, print Not found. For this set, assume 1 <= n <= 25.

import java.util.Scanner;
public class ProductLookup {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        String[] name = new String[n];
        double[] price = new double[n];
        for (int i = 0; i < n; i++) {
            name[i] = sc.next();
            price[i] = sc.nextDouble();
        }
        String key = sc.next();
        int found = -1;
        for (int i = 0; i < n; i++)
            if (name[i].equals(key)) {
                found = i;
                break;
            }
        if (found == -1) System.out.println("Not found");
        else System.out.println(price[found]);
    }
}

import java.util.Scanner;
public class DiagonalCompare {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int[][] a = new int[5][5];
        for (int i = 0; i < 5; i++)
            for (int j = 0; j < 5; j++)
                a[i][j] = sc.nextInt();
        int left = 0, right = 0;
        for (int i = 0; i < 5; i++) {
            left += a[i][i];
            right += a[i][4 - i];
        }
        System.out.println(left + " " + right);
        System.out.println(left == right ? "Equal" : "Unequal");
    }
}
8 [15]
Read letters and spaces. Print each palindrome word of at least 3 letters, ignoring case; display in uppercase. Repeated spaces are allowed. Print the final count.
Worked solution / model answer
Extract words, reverse each word using charAt, and compare using equals.
Check: One-letter words do not qualify in this task. Reset the word after each delimiter.

import java.util.Scanner;
public class PalindromeWords {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine().toUpperCase() + " ";
        String word = "";
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c != ' ') word += c;
            else {
                String reverse = "";
                for (int j = word.length() - 1; j >= 0; j--)
                    reverse += word.charAt(j);
                if (word.length() >= 3 && word.equals(reverse)) {
                    System.out.println(word);
                    count++;
                }
                word = "";
            }
        }
        System.out.println("Count = " + count);
    }
}
