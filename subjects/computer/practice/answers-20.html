Define WaterBill with String name, int units and double bill. accept() reads name and non-negative units; calculate() charges Rs 12 per unit for the first 50 units, Rs 10 for the next 50, and Rs 12 thereafter. Add 5% of the calculated charge only when units exceed 100. display() prints name and bill. main() must create an object and invoke the methods. Input: a full name on one line, then units.
Worked solution / model answer
Keep fields at class scope. Carry forward the cost of each completed slab, then add the surcharge.
Check: A progressive slab is different from charging every unit at the final rate. Test both sides of each boundary.

import java.util.Scanner;
public class WaterBill {
    String name;
    int units;
    double bill;
    void accept() {
        Scanner sc = new Scanner(System.in);
        name = sc.nextLine();
        units = sc.nextInt();
    }
    void calculate() {
        if (units <= 50) bill = units * 12.0;
        else if (units <= 100)
            bill = 400 + (units - 50) * 10.0;
        else {
            bill = 900 + (units - 100) * 12.0;
            bill += bill * 0.05;
        }
    }
    void display() {
        System.out.println(name);
        System.out.println(bill);
    }
    public static void main(String[] args) {
        WaterBill w = new WaterBill();
        w.accept();
        w.calculate();
        w.display();
    }
}

Overload show: void show(int rows) prints rows lines, with line i containing i through rows; int show(String text, char target) returns the case-sensitive frequency of target; double show(double radius) returns Math.PI * radius * radius. main() demonstrates show(8), show("APPLICATION",'P') and show(6.0).
Worked solution / model answer
The parameter lists select the overload. Use nested for loops for the triangle and a single String traversal for frequency.
Check: Return type alone does not overload a method. show(2) chooses the int overload; show(2.0) chooses double.

public class Revision {
    void show(int rows) {
        for (int i = 1; i <= rows; i++) {
            for (int j = i; j <= rows; j++) {
                if (j > i) System.out.print(" ");
                System.out.print(j);
            }
            System.out.println();
        }
    }
    int show(String text, char target) {
        int count = 0;
        for (int i = 0; i < text.length(); i++)
            if (text.charAt(i) == target) count++;
        return count;
    }
    double show(double radius) {
        return Math.PI * radius * radius;
    }
    public static void main(String[] args) {
        Revision r = new Revision();
        r.show(8);
        System.out.println(r.show("APPLICATION", 'P'));
        System.out.println(r.show(6.0));
    }
}

Accept a complete line. Count uppercase letters, lowercase letters, digits, and all other characters (including spaces). Print the counts in this order: uppercase letters, digits, other characters, lowercase letters.
Worked solution / model answer
Use an if/else-if chain so each character enters exactly one category.

import java.util.Scanner;
public class CharAudit {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine();
        int upper = 0, lower = 0, digits = 0, other = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (Character.isUpperCase(c)) upper++;
            else if (Character.isLowerCase(c)) lower++;
            else if (Character.isDigit(c)) digits++;
            else other++;
        }
        System.out.println(upper + " " + digits + " " + other + " " + lower);
    }
}
6 [15]
Read 9 one-word names, convert them to uppercase, and arrange them in descending alphabetical order using selection sort only. Print one name per line.
Worked solution / model answer
For each position find the largest remaining String using compareTo, then swap once.
Check: For descending order, choose a candidate when compareTo is positive. Do not sort using a library routine.

import java.util.Scanner;
public class SelectionNames {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String[] a = new String[9];
        for (int i = 0; i < 9; i++)
            a[i] = sc.next().toUpperCase();
        for (int i = 0; i < a.length - 1; i++) {
            int best = i;
            for (int j = i + 1; j < a.length; j++)
                if (a[j].compareTo(a[best]) > 0) best = j;
            String temp = a[i];
            a[i] = a[best];
            a[best] = temp;
        }
        for (int i = 0; i < a.length; i++)
            System.out.println(a[i]);
    }
}

import java.util.Scanner;
public class RotateWord {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next().toUpperCase();
        int split = -1;
        for (int i = 0; i < s.length(); i++)
            if ("AEIOU".indexOf(s.charAt(i)) >= 0) {
                split = i;

    }
}

Read choice. Choice 1 reads n and x, then prints x^5 - x^6 + x^7 - ... through n terms. Choice 2 reads n and prints 1! + 2! + ... + n!. Assume 1 <= n <= 12. For any other choice print Invalid choice. Use switch.
Worked solution / model answer
Use the term position for alternating sign. For factorials, carry a running product and add it after each multiplication.
Check: Use a floating-point accumulator for powers. Initialize factorial to 1 outside the loop. Include break and default.

import java.util.Scanner;
public class MenuSeries {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int choice = sc.nextInt();
        switch (choice) {
            case 1: {
                int n = sc.nextInt();
                double x = sc.nextDouble(), sum = 0;
                for (int i = 1; i <= n; i++) {
                    double term = Math.pow(x, i + 4);
                    if (i % 2 == 1) sum += term;
                    else sum -= term;
                }
                System.out.println(sum);
                break;
            }
            case 2: {
                int n = sc.nextInt();
                long factorial = 1, sum = 0;
                for (int i = 1; i <= n; i++) {
                    factorial *= i;
                    sum += factorial;
                }
                System.out.println(sum);
                break;
            }
            default: System.out.println("Invalid choice");
        }
    }
}
