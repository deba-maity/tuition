Define WaterBill with String name, int units and double bill. accept() reads name and non-negative units; calculate() charges Rs 10 per unit for the first 50 units, Rs 10 for the next 50, and Rs 10 thereafter. Add 5% of the calculated charge only when units exceed 100. display() prints name and bill. main() must create an object and invoke the methods. Input: a full name on one line, then units.
Worked solution / model answer
Keep fields at class scope. Carry forward the cost of each completed slab, then add the surcharge.
Check: A progressive slab is different from charging every unit at the final rate. Test both sides of each boundary.

import java.util.Scanner;
public class WaterBill {
    String name;
    int units;
    double bill;
    void accept() {
        Scanner sc = new Scanner(System.in);
        name = sc.nextLine();
        units = sc.nextInt();
    }
    void calculate() {
        if (units <= 50) bill = units * 10.0;
        else if (units <= 100)
            bill = 300 + (units - 50) * 10.0;
        else {
            bill = 700 + (units - 100) * 10.0;
            bill += bill * 0.05;
        }
    }
    void display() {
        System.out.println(name);
        System.out.println(bill);
    }
    public static void main(String[] args) {
        WaterBill w = new WaterBill();
        w.accept();
        w.calculate();
        w.display();
    }
}

Overload show: void show(int rows) prints rows lines, with line i containing i through rows; int show(String text, char target) returns the case-sensitive frequency of target; double show(double radius) returns Math.PI * radius * radius. main() demonstrates show(6), show("MISSISSIPPI",'S') and show(4.0).
Worked solution / model answer
The parameter lists select the overload. Use nested for loops for the triangle and a single String traversal for frequency.
Check: Return type alone does not overload a method. show(2) chooses the int overload; show(2.0) chooses double.

public class Revision {
    void show(int rows) {
        for (int i = 1; i <= rows; i++) {
            for (int j = i; j <= rows; j++) {
                if (j > i) System.out.print(" ");
                System.out.print(j);
            }
            System.out.println();
        }
    }
    int show(String text, char target) {
        int count = 0;
        for (int i = 0; i < text.length(); i++)
            if (text.charAt(i) == target) count++;
        return count;
    }
    double show(double radius) {
        return Math.PI * radius * radius;
    }
    public static void main(String[] args) {
        Revision r = new Revision();
        r.show(6);
        System.out.println(r.show("MISSISSIPPI", 'S'));
        System.out.println(r.show(4.0));
    }
}
5 [15]
Accept 8 single-character tokens. Copy them into a second array. Sort the copy in ascending character-code order using bubble sort only. Display the original and sorted sequences.
Worked solution / model answer
After each left-to-right pass, the greatest remaining character reaches the right end.
Check: Use j < length - 1 - pass. Preserve the original by copying elements, not by assigning the same array reference.

import java.util.Scanner;
public class BubbleChars {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        char[] original = new char[8], a = new char[8];
        for (int i = 0; i < 8; i++) {
            original[i] = sc.next().charAt(0);
            a[i] = original[i];
        }
        for (int pass = 0; pass < a.length - 1; pass++)
            for (int j = 0; j < a.length - 1 - pass; j++)
                if (a[j] > a[j + 1]) {
                    char temp = a[j];
                    a[j] = a[j + 1];
                    a[j + 1] = temp;
                }
        for (int i = 0; i < 8; i++)
            System.out.print(original[i] + " ");
        System.out.println();
        for (int i = 0; i < 8; i++)
            System.out.print(a[i] + " ");
        System.out.println();
    }
}

Read a sentence containing only English letters and spaces. Print, in uppercase, each word beginning with a vowel and ending with a vowel. Print Count = followed by the count. Treat A E I O U as vowels. Allow repeated spaces.
Worked solution / model answer
Append a trailing space to process the final word. Build each word, test its first and last letters, then reset it.
Check: Check that the word is non-empty before charAt. A consonant is a letter that is not one of the five vowels.

import java.util.Scanner;
public class WordFilter {
    static boolean vowel(char c) {
        return "AEIOU".indexOf(c) >= 0;
    }
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine().toUpperCase() + " ";
        String word = "";
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c != ' ') word += c;
            else {
                if (word.length() > 0
                    && vowel(word.charAt(0))
                    && vowel(word.charAt(word.length() - 1))) {
                    System.out.println(word);
                    count++;
                }
                word = "";
            }
        }
        System.out.println("Count = " + count);
    }
}
7 [15]
Read a 5 by 6 matrix. Print zero count and non-zero count. Print Sparse only if zeros strictly outnumber non-zeros; otherwise print Not sparse.
Worked solution / model answer
Count zeros in a nested loop; obtain non-zeros from 12 minus zeros.
Check: An equal split is not sparse under this definition. Use >, not >=.

import java.util.Scanner;
public class SparseCheck {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int[][] a = new int[5][6];
        int zero = 0;
        for (int i = 0; i < 5; i++)
            for (int j = 0; j < 6; j++) {
                a[i][j] = sc.nextInt();
                if (a[i][j] == 0) zero++;
            }
        int nonzero = 12 - zero;
        System.out.println(zero + " " + nonzero);
        System.out.println(zero > nonzero ? "Sparse" : "Not sparse");
    }
}

Read positive n, then n integers into an array. Print minimum, maximum and total in that order. Values can be negative. Then print the count of elements divisible by 4.

import java.util.Scanner;
public class ArraySummary {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextInt();
        int min = a[0], max = a[0];
        long total = 0;
        for (int i = 0; i < n; i++) {
            if (a[i] < min) min = a[i];
            if (a[i] > max) max = a[i];
            total += a[i];
        }
        System.out.println(min + " " + max + " " + total);
        int matches = 0;
        for (int i=0;i<n;i++) if(a[i] % 4 == 0) matches++;
        System.out.println(matches);
    }
}
