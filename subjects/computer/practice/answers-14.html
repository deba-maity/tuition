Define WaterBill with String name, int units and double bill. accept() reads name and non-negative units; calculate() charges Rs 7 per unit for the first 50 units, Rs 9 for the next 50, and Rs 11 thereafter. Add 5% of the calculated charge only when units exceed 100. display() prints name and bill. main() must create an object and invoke the methods. Input: a full name on one line, then units.
Worked solution / model answer
Keep fields at class scope. Carry forward the cost of each completed slab, then add the surcharge.
Check: A progressive slab is different from charging every unit at the final rate. Test both sides of each boundary.

import java.util.Scanner;
public class WaterBill {
    String name;
    int units;
    double bill;
    void accept() {
        Scanner sc = new Scanner(System.in);
        name = sc.nextLine();
        units = sc.nextInt();
    }
    void calculate() {
        if (units <= 50) bill = units * 7.0;
        else if (units <= 100)
            bill = 350 + (units - 50) * 9.0;
        else {
            bill = 800 + (units - 100) * 11.0;
            bill += bill * 0.05;
        }
    }
    void display() {
        System.out.println(name);
        System.out.println(bill);
    }
    public static void main(String[] args) {
        WaterBill w = new WaterBill();
        w.accept();
        w.calculate();
        w.display();
    }
}

Overload show: void show(int rows) prints rows lines, with line i containing i through rows; int show(String text, char target) returns the case-sensitive frequency of target; double show(double radius) returns 2 * Math.PI * radius (circumference). main() demonstrates show(7), show("CALCULATOR",'L') and show(5.0).
Worked solution / model answer
The parameter lists select the overload. Use nested for loops for the triangle and a single String traversal for frequency.
Check: Return type alone does not overload a method. show(2) chooses the int overload; show(2.0) chooses double.

public class Revision {
    void show(int rows) {
        for (int i = 1; i <= rows; i++) {
            for (int j = i; j <= rows; j++) {
                if (j > i) System.out.print(" ");
                System.out.print(j);
            }
            System.out.println();
        }
    }
    int show(String text, char target) {
        int count = 0;
        for (int i = 0; i < text.length(); i++)
            if (text.charAt(i) == target) count++;
        return count;
    }
    double show(double radius) {
        return 2 * Math.PI * radius;
    }
    public static void main(String[] args) {
        Revision r = new Revision();
        r.show(7);
        System.out.println(r.show("CALCULATOR", 'L'));
        System.out.println(r.show(5.0));
    }
}
5 [15]
Accept a complete line. Count uppercase letters, lowercase letters, digits, and all other characters (including spaces). Print the counts in this order: lowercase letters, other characters, uppercase letters, digits.
Worked solution / model answer
Use an if/else-if chain so each character enters exactly one category.
Check: Do not classify punctuation as lowercase. A space belongs to the explicitly defined other category.

import java.util.Scanner;
public class CharAudit {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine();
        int upper = 0, lower = 0, digits = 0, other = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (Character.isUpperCase(c)) upper++;
            else if (Character.isLowerCase(c)) lower++;
            else if (Character.isDigit(c)) digits++;
            else other++;
        }
        System.out.println(lower + " " + other + " " + upper + " " + digits);
    }
}

Read a positive int n. Print Balanced if the sum of its decimal digits is divisible by 5, otherwise print Not balanced. Use a digit-extraction loop. Do not convert the number to a String.
Worked solution / model answer
Use n % 10 for the final digit, n / 10 to remove it, and keep the digit count and sum separately.
Check: Preserve the original if needed for output. Do not learn a number name without its exact supplied definition.

import java.util.Scanner;
public class BalancedDigits {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(), temp = n;
        int sum = 0, count = 0;
        while (temp > 0) {
            sum += temp % 10;
            count++;
            temp /= 10;
        }
        if (sum % 5 == 0)
            System.out.println("Balanced");
        else System.out.println("Not balanced");
    }
}
7 [15]
Read a 6 by 6 integer matrix and print sqrt of the sum of squares of all its elements. Use Math.sqrt.
Worked solution / model answer
Accumulate squared values in a double, then take exactly one square root at the end.
Check: This is not the sum of individual square roots and not the square of the total sum.

import java.util.Scanner;
public class MatrixNorm {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int[][] a = new int[6][6];
        double squares = 0;
        for (int i = 0; i < 6; i++)
            for (int j = 0; j < 6; j++) {
                a[i][j] = sc.nextInt();
                squares += (double)a[i][j] * a[i][j];
            }
        System.out.println(Math.sqrt(squares));
    }
}

Define fields String name, double price, double payable. Supply a no-argument constructor and BookDiscount(String name, double price). calculate() gives a whole-price discount of 5% up to Rs 2500, 10% above 2500 up to 6000, and 15% above 6000. display() prints name and payable. main() reads name then price and uses the parameterized constructor.
Worked solution / model answer
Select one discount percentage for the entire price; this is not a progressive slab.
Check: Constructor names exactly match the class and have no return type. this.name distinguishes the field from the parameter.

import java.util.Scanner;
public class BookDiscount {
    String name;
    double price, payable;
    BookDiscount() { this("", 0); }
    BookDiscount(String name, double price) {
        this.name = name;
        this.price = price;
    }
    void calculate() {
        double rate;
        if (price <= 2500) rate = 5;
        else if (price <= 6000) rate = 10;
        else rate = 15;
        payable = price - price * rate / 100.0;
    }
    void display() {
        System.out.println(name);
        System.out.println(payable);
    }
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String name = sc.nextLine();
        double price = sc.nextDouble();
        BookDiscount b = new BookDiscount(name, price);
        b.calculate();
        b.display();
    }
}
